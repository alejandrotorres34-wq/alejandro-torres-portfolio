# Alejandro Torres Portfolio Website

This folder contains a static recruiter portfolio website.

## Files
- `index.html` — main website
- `assets/styles.css` — styling
- `assets/img/` — project images
- `assets/files/Alejandro_Torres_Portfolio.pdf` — downloadable PDF portfolio/resume

## Fastest way to get a public URL
1. Go to Netlify Drop.
2. Drag the entire `alejandro_torres_portfolio_site` folder into the page.
3. Netlify will create a public URL immediately.
4. Rename the site URL in Netlify settings if desired.

## GitHub Pages option
1. Create a public GitHub repository named `alejandro-torres-portfolio`.
2. Upload all files from this folder.
3. Go to Settings → Pages.
4. Set the source to the `main` branch and `/root` folder.
5. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/alejandro-torres-portfolio/`
